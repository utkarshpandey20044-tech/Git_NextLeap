# SBI Mutual Fund Facts Assistant

A facts-only RAG chatbot for factual questions about selected SBI Mutual
Fund schemes.

## Product

-   **Product/platform:** Groww
-   **AMC:** SBI Mutual Fund
-   **Schemes covered:**
    -   SBI Large Cap Fund
    -   SBI Flexicap Fund
    -   SBI Multicap Fund
    -   SBI ELSS Tax Saver Fund

The chatbot uses only approved public sources from SBI Mutual Fund,
SEBI, and AMFI.

## What the assistant can answer

Examples include:

-   Expense ratio / TER
-   Exit load
-   Minimum SIP / minimum investment
-   ELSS lock-in
-   Benchmark
-   Riskometer / risk level
-   How to access account statements

The assistant is intentionally facts-only. It does not provide
investment advice, portfolio recommendations, rankings, or
performance-based comparisons.

## Architecture

``` text
User question
     |
     v
PII / intent guardrails
     |
     +---- Advice ------> Refusal + official educational link
     |
     +---- Performance --> Refusal + official source link
     |
     +---- PII ----------> Privacy refusal
     |
     v
Scheme + fact-type detection
     |
     v
ChromaDB semantic retrieval
     |
     v
Official source evidence
     |
     v
Google Gemini
     |
     v
Concise answer + one official source URL
```

### Retrieval design

Embeddings are generated locally with:

`sentence-transformers/all-MiniLM-L6-v2`

The vectors are stored in ChromaDB.

For selected structured facts, retrieval uses source routing:

-   Benchmark → dedicated scheme page first, then factsheet fallback
-   Exit load → dedicated scheme page first, then factsheet fallback
-   Minimum SIP → factsheet first
-   Other supported factual queries → scheme-aware retrieval / general
    retrieval

The final answer is generated by Google Gemini using only the retrieved
evidence.

## Data corpus

The corpus contains **15 official public sources** and produces
approximately **3,861 chunks**.

Source types include:

-   SBI Mutual Fund factsheet index
-   SBI Mutual Fund scheme pages
-   SBI Mutual Fund SID/KIM documents
-   SBI Mutual Fund TER page
-   SBI Mutual Fund Ways to Invest page
-   SBI Mutual Fund factsheets
-   SEBI Mutual Fund Master Circular
-   AMFI TER database

See `data/sources.csv` for the complete source list.

## Privacy and safety

The application:

-   Does not request or require PAN, Aadhaar, OTP, account numbers,
    phone numbers, or email addresses.
-   Detects common personal identifiers before retrieval.
-   Refuses investment advice and recommendations.
-   Refuses performance/return-based questions.
-   Does not use personal financial information.
-   Does not connect to a user's Groww account or any private investment
    account.

## Setup

### 1. Create and activate a virtual environment

Windows PowerShell:

``` powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 2. Install dependencies

``` powershell
pip install -r requirements.txt
```

### 3. Configure Gemini

Create a `.env` file in the project root:

``` text
GEMINI_API_KEY=your_key_here
```

Never commit `.env` or expose the API key publicly.

### 4. Collect the approved sources

``` powershell
python src/collect_sources.py
```

### 5. Extract text

``` powershell
python src/extract_text.py
```

### 6. Create chunks

``` powershell
python src/chunk_documents.py
```

### 7. Build the local vector database

``` powershell
python src/build_vector_db.py
```

### 8. Run the application

``` powershell
streamlit run app.py
```

## Known limitations

-   The corpus is limited to the selected SBI Mutual Fund schemes and
    approved official public sources.
-   Source information can change after the corpus is collected; the
    source date shown in an answer is based on information explicitly
    available in the retrieved source.
-   The assistant is not a personalized financial advisor.
-   Performance and recommendation questions are intentionally
    restricted.
-   The prototype uses a small, curated corpus rather than the full
    mutual-fund universe.
-   The local Chroma database is generated from the source corpus and is
    not committed to GitHub.

## Disclaimer

This assistant provides factual information about selected mutual fund
schemes using official public sources. It does not provide investment
advice, recommendations, portfolio guidance, performance-based
comparisons, or personalized financial advice.

-   W1: fact-vs-advice intent handling
-   W2: prompting, refusal behavior, and source citations
